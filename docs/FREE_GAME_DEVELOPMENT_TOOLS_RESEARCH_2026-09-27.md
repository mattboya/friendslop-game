# Free, agent usable tools for *After Hours*

27 September 2026 · Research only. No software, package, asset, or plugin was downloaded or installed for this note.

## Decision

Keep the existing Blender → FBX/PNG → Unity URP pipeline. The most useful new tool to evaluate for the [graphics upgrade plan](GRAPHICS_UPGRADE_PLAN_2026-09-27.md) is **Material Maker** for repeatable procedural material maps. **ImageMagick is already installed** and can immediately help inspect and prepare texture sets. Inkscape, GIMP, FFmpeg, Krita, Audacity, and Poly Haven fill narrower gaps. Codex and Claude can both drive ordinary documented command line, Python, and HTTP interfaces if those tools are available in their execution environment; this is an interface assessment, not a claim that Claude has been configured or tested here. Unity interaction has separate agent access terms discussed below.

The project currently uses generated Blender sources, FBX exports, and PNG textures. Its `scripts/art-pipeline.mjs` already runs Blender in the background and stages outputs before publication; `Packages/manifest.json` includes URP but not the optional Unity packages below. See [asset provenance](ASSET_PROVENANCE.md) and the [art pipeline](../scripts/art-pipeline.mjs). The older [toolchain note](TOOLCHAIN.md) records the project's initial setup and is not a current installation inventory.

Local check today: `/Applications/Blender.app`, Unity 6000.3.24f1, and `/opt/homebrew/bin/magick` are present. `ffmpeg`, GIMP, Krita, Inkscape, Audacity, and Material Maker were not found on PATH or at the standard `/Applications` app paths checked. This check does not rule out copies in other directories.

## Free asset source, with a separate license boundary

**Poly Haven** is a source of HDRIs, textures, and models rather than an authoring application. Its [asset license](https://polyhaven.com/license) says published assets are CC0 and may be used commercially without attribution. Its [current API page, dated 18 July 2026](https://polyhaven.com/our-api), says the live API is also free for commercial use and offers metadata, file URLs, sizes, and hashes suitable for scripts. The API requires a unique `User-Agent`; a tool that exposes the live API to its users must clearly credit Poly Haven. The CC0 asset license and API service terms are distinct. The library also has [early access Vault collections](https://polyhaven.com/vaults) that require Patreon access until released, and its [Blender asset browser add-on](https://polyhaven.com/donate) is a patron benefit, so neither belongs in a strict free-only workflow today.

For *After Hours*, use a selected CC0 HDRI as a lighting reference or a texture as a controlled base, then art direct and recolor it to the game's dusk palette. A realistic downloaded model dropped into a stylized scene is likely to clash with the original characters. Record asset ID, source URL, license, chosen resolution, and file hash in [asset provenance](ASSET_PROVENANCE.md) if anything is later imported. **Nothing was imported for this research.**

## Already in Unity, or optional Unity packages

Unity documents [batch mode and `-executeMethod`](https://docs.unity3d.com/ja/current/Manual/EditorCommandLineArguments.html) for project C# editor scripts, and the project has a [Unity command wrapper](../scripts/unity.mjs). Its [Profiler](https://docs.unity3d.com/jp/current/Manual/Profiler.html) and [Frame Debugger](https://docs.unity3d.com/cn/2023.1/Manual/frame-debugger-window.html) can identify actual CPU/GPU/rendering costs before raising quality settings; these are part of Unity rather than extra installs. **Agent control is a separate question:** Unity's [June 2026 Terms of Service](https://unity.com/legal/terms-of-service) say AI agents, LLMs, and MCP clients or servers may interact with the Unity platform only through a framework operated or designated by Unity. The existence of a CLI does not by itself establish that a particular Codex or Claude integration is designated. Confirm the permitted route for agent driven Editor actions before adding or relying on a Unity agent bridge. This note makes no legal conclusion about a specific existing script invocation.

Two official packages may be valuable later. [Animation Rigging](https://docs.unity3d.com/ja/Packages/com.unity.animation.rigging%401.2/manual/index.html) provides constraint based secondary motion and IK; [Two Bone IK](https://docs.unity3d.com/ja/Packages/com.unity.animation.rigging%401.2/manual/constraints/TwoBoneIKConstraint.html) could help hands meet carried props or stage controls. [Unity Recorder](https://docs.unity3d.com/ja/6000.0/Manual/com.unity.recorder.html) can capture Editor Play mode images, video, animation, and audio for consistent art review. Neither is in the current project manifest, and their compatible versions and package licenses should be checked in this exact Unity editor before adding them. Unity's [Companion License](https://unity.com/legal/licenses/unity-companion-license) is no charge for use connected to a valid Unity engine license, while [Unity Personal's current eligibility](https://unity.com/products/unity-personal) depends on the previous 12 months' revenue and funds raised. These packages are not a substitute for authored motion or native build validation.

### Agent bridge watchlist

- [Blender Lab's MCP server](https://www.blender.org/lab/mcp-server/) is a first party experimental route for an MCP capable client, including a possible Claude or Codex connection. It requires Blender 5.1+, a separate add-on and server installation, and the Blender page warns that LLM generated code executes **without guards**. The installed Blender is 5.2.2 LTS, but no MCP component was installed or tested. The existing scripted Blender pipeline is the more controlled choice for now.
- [Unity's official MCP server](https://unity.com/blog/unity-ai-how-to-get-started) supports external agents including Claude and Codex, but Unity says Personal users receive it on a **free trial**, while ongoing inclusion is attached to paid Pro, Enterprise, and Industry subscriptions. It therefore does not qualify as a durable zero cost recommendation. The [Unity agent access terms](https://unity.com/legal/terms-of-service) also mean an arbitrary community MCP server should not be assumed permitted.

## Suggested order, without installing anything now

1. Use the existing Blender/Unity pipeline and the installed ImageMagick to define texture dimensions, capture comparisons, and material checks for one camp → market → stage sample.
2. If the material pass is slow, trial Material Maker on one canvas/wood/metal set, stage the maps, and inspect the URP result in gameplay before adopting its export format more broadly.
3. Add Inkscape if icons and signs need a coherent vector source. Add GIMP or Krita when a human art pass needs layered raster painting; choose based on the actual workflow.
4. Add FFmpeg when there are repeatable capture/audio review jobs. Add Audacity for recorded sound editing. Consider Poly Haven assets selectively with provenance and art direction.

These are **research recommendations**, not installation or integration results. Any future introduction should keep source files, scripted export commands, import settings, and license records together. The visual acceptance gate remains the [graphics plan's](GRAPHICS_UPGRADE_PLAN_2026-09-27.md) native playable sample and performance check.
